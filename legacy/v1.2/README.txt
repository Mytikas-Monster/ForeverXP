ForeverXP 1.2 — WoW: Forever (Interface 16001)

INSTALLATION
Extract the ForeverXP folder to your game's Interface/AddOns directory.
Restart the game and enable ForeverXP.

COMMANDS
/fxp       Show window
/fxp hide  Hide window
/fxp reset Reset XP measurement

WINDOW
Drag the window body to move it; drag the bottom-right grip to resize it.
Position and dimensions are saved on logout/reload.

NOTES
The S–F thresholds are illustrative benchmarks discussed in chat, not
verified Forever population rankings. The three ranked signals are measured
proxies, not causal attribution or accurate XP/hour loss estimates.
Session XP resets on login/reload. Some XP gains across unusual multi-level
jumps may be miscounted. Group kill counting is incomplete.

This build is not yet tested inside the Forever client. If it fails to load,
share the first Lua error (enable scriptErrors with /console scriptErrors 1).
